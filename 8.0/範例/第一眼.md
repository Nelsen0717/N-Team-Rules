# 第一眼：從老闆的網址一分鐘內看什麼

挑 3 件看得到、不用登入的事實寫進報告頁的第一眼。每件標「已驗證」附連結，看不準的標「推測」。不下診斷結論。

| 網址 | 看什麼（挑 3 件） |
|---|---|
| Google 地圖 | 分數和評論數、最近一則評論的日期、有沒有回評論、營業時間有沒有寫 |
| IG／Threads／FB | 最近一次發文是哪天、首頁有沒有寫怎麼預約或價目、置頂貼文講什麼 |
| 官網 | 首頁第一段有沒有講賣什麼和給誰、有沒有價格、怎麼預約、最後更新日期 |
| 沒有網址 | 寫「還沒有公開資料」，用老闆那一句話預填第 1 題 |

例：「已驗證：Google 評論 38 則，最近一則 10/28（連結）」「推測：價目沒有寫在 IG 首頁，客人可能要私訊才知道」。
