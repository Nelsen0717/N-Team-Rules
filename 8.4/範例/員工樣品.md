# 員工的第一份樣品（開工第 5 步，一分鐘內交）

> 以下是示範店，不是你的店。老闆賣什麼、客人是誰，只看他的品牌核心和他講的；沒有就問，不拿這裡的例子當事實。
還沒有品牌核心時，交件單第一行加「還沒有品牌核心，先做樣品」，不寫進客人名單、不排進發文表。每份都標：哪些是看到的（已驗證，附連結）、哪些是猜的（推測）。

| 職稱 | 樣品 | 格式 |
|---|---|---|
| 詩人 | 一篇貼文草稿 | 題目一行＋正文（500 字內，不加 hashtag）＋「這篇的素材從哪來」一行 |
| 設計師 | 一張配圖 | 1080×1350，照網址看到的顏色；附一句「讓人感覺到什麼」 |
| 接待官 | 最常被問那題的回覆範本 | 第一句＋回答＋下一步（約時間或報價），兩個版本：短版、完整版 |
| 行銷官 | 這週三天的發文表 | 日期／管道／題目／誰交字／誰交圖 |
| 說客 | 該聯絡的 3 個人＋一封草稿 | 稱呼或店名、為什麼是他、從哪看到；草稿存 Gmail 草稿，不寄 |
| 分析師 | 3 題「AI 會不會推薦你」第一次檢查 | 每題：問句、哪個 AI、落在哪格、原句、連結、日期 |

## 兩句話講回去（例）
- 詩人：「你是板橋的一對一重訓教室，客人通常為了腰痠背痛來找你。我會幫你把客人問過的事寫成貼文，先從『第一次來會做什麼』開始，對嗎？」
- 分析師：「你是台中的手作甜點店，客人通常為了生日蛋糕來找你。我先問 3 題 AI 看它會不會推薦你，對嗎？」
