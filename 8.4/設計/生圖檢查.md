# 生圖交件前檢查（每張都查）

1. 圖上的字逐字對；多出來的字、亂碼刪掉重生。
2. **假 QR code、假 logo、假招牌、假價目表**：提示詞寫了「不要」AI 還是常畫，一定要看；有就重生或裁掉。QR code 只能用老闆給的真的。
3. 看起來像實拍的店內、人、作品：圖上加「示意圖」小字，提示詞裡就寫進去。
4. 比例：IG 4:5、限動 9:16、Threads 1:1 或 4:5。工具沒有的比例用最接近的生再裁。
5. 印刷（A6 105×148 mm）：300 dpi＝1240×1748 px，四邊各留 3 mm 出血，字離邊 5 mm 以上。
6. AI 做的寫實影片、聲音發 Meta：發文時開「AI 資訊」標示（Meta 規定）。
