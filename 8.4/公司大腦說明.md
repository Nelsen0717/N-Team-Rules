# 公司大腦說明（資料夾、誰寫哪個檔、欄位）

> 以下是示範店，不是你的店。老闆賣什麼、客人是誰，只看他的品牌核心和他講的；沒有就問，不拿這裡的例子當事實。
> 範本裡只留資料夾清單和「怎麼算一位」。這份講：每個檔誰寫、什麼時候寫、欄位是什麼、數字怎麼回到老闆面前。

## 一句話規則
- 一個檔只有一位主寫（下表「主寫」）。別人要改：寫交件單給主寫，或只填自己那一欄、那一分頁。
- 外面來的數字（店家系統、平台後台、廣告）先放「店裡的數字/原始檔/」，原檔不改不刪；算好的數字才進表。
- 對不上的時候以客人名單為準，差多少寫出來，不相加、不猜原因。
- 數字標來源和日期；查不到寫「查不到」，不知道寫「待補」，不是 0。
- 舊資料夾（有編號的、叫「圖片」的）照用，不另開同名資料夾。

## 數字怎麼回到老闆面前
1. 員工照上表寫檔，交件單寫「做了什麼／放哪／數字附出處」。
2. 分析師週日 16:00 收齊：客人名單、發文表、帳號表、廣告紀錄、數字總表 → 每週記分板 Page，文字版存報告/每週記分板/日期。
3. 大總管週一 10:00 週會：一頁講離目標多遠、最卡一站、要老闆決定的最多三件。
4. 每天開門只講今天三件事；數字有變差才講。
5. 每月第一個週日：分析師照〈分析/網站與廣告怎麼看.md〉出一張表＋三句，存報告/每月/。

## 客人名單欄位
| 欄 | 寫什麼 |
|---|---|
| 稱呼 | 老闆怎麼叫他，不寫全名 |
| 來源 | 哪個管道：Threads、IG、FB 粉專、FB 社團、LINE 官方帳號、Google 地圖、官網、廣告、介紹、舊識、名錄、走進來；同一管道再細分寫「・」後面（例「IG・留言就送」） |
| 狀態 | 詢問 → 洽談 → 成交 → 備妥 → 完成 → 回流；停止＝說不要，永不再排 |
| 負責 | 職稱 |
| 下一步、下一步日期 | 一句話＋日期 |
| 最近一筆 | 日期和金額區間 |
| 上次到店、到店次數、週期（天） | 算回頭客和流失客用 |
| 客群 | 新客、熟客、回頭客、流失客 |
| 介紹人 | 稱呼 |
| 系統編號 | 選填：店家系統的會員或訂單編號，用來對帳去重；不放電話、信箱 |
不放電話、信箱、地址、私事（健康、宗教、財務）。

### 來往紀錄（同一份試算表的第二分頁）
日期、稱呼、管道、發生什麼（一句，不貼對話原文）、狀態變成、誰記。每推一次狀態就一列；名單那列只留最新。

### 什麼人進名單
只收有下一步的人：來問的、在談的、買過要叫回的、有人介紹的。店家系統裡的整批會員不搬進來，只在數字總表記人數；要叫回某幾位時，才一位一位加進名單。

## 發文表欄位（每篇每個管道一列）
編號（日期-管道-序）、預定日期時間、管道、題目、客人原話出處、全文（草稿/ 檔連結）、素材（素材/ 檔連結，圖或影片）、誰寫字、誰做圖、狀態（排了／字到了／圖到了／待老闆／已發）、發文連結、
發後 2 天：留言、私訊、來問幾位；發後 7 天：留言、私訊、來問幾位、觸及（參考）、收藏或分享（參考）、數字從哪來和日期、備註。
- LINE 群發也一列：管道寫「LINE」，多填給哪一群、送出幾則、回了幾位、來約幾位。
- 2 天數字：大總管開門時問老闆，或照〈連線/總覽.md〉從 Buffer、瀏覽器讀；7 天數字：分析師週日補。
- 「來問幾位」對不上客人名單，以名單為準。

## 帳號表
### 帳號分頁（一個帳號一列）
管道、帳號名、網址、用來做什麼、誰顧（職稱）、怎麼連（Buffer／瀏覽器＋Vault／匯出檔／官方連線／老闆自己）、登入存在 Vault 了沒（只寫有或沒有，不寫帳密）、狀態（在用／還沒串／停用）、上次讀到數字的日期。店家系統（POS、網店、訂位）也列在這。
### 每週數字分頁（一個帳號一週一列）
週（週一日期）、管道、粉絲或好友數、這週新增、封鎖（LINE）、發了幾篇、留言、私訊、來問幾位、數字從哪來和日期。

## 廣告紀錄（一支廣告一列）
編號、平台、開始、結束、目的（私訊／預約／到店／買）、給誰看、每天預算、老闆說好的日期、
花費、私訊開始、預約或購買、每個預約花多少、一次客單價、判斷（划算／在虧／待補）、匯出檔連結、備註。
- 錢的事老闆點頭才開、才加錢；沒有「老闆說好的日期」的那列不准開。
- 員工只看、只記、只起草，不自己改廣告。

## 數字總表（店裡的數字/）
一個來源一週一列：週、來源、營收、訂單數或來客數、平均一筆多少、新會員、回購或回頭、取消或退款、沒到（訂位）、原始檔連結、誰填。
原始檔命名：`來源-內容-起日_迄日`（例：iCHEF-營業報表-20261026_20261101.xlsx）。含電話、信箱的原始檔不分享、不貼進對話，算完數字照放著。

## 靈感池、客人見證庫
靈感池：點子、來源（客人問過／同行／AI 檢查／老闆想到）、狀態（點子 → 排隊 → 寫好 → 老闆看過 → 已發；不做）、誰寫、哪天發、連結。
客人見證庫：原句（逐字）、誰說的（可匿名）、日期、出處、能支持哪一句話、同意狀態（沒問過／問過了／可以公開／只能匿名／改過字後同意／拒絕）。

## 送出紀錄
時間、類型（發文／私訊／回評論／改後台設定／開或停廣告）、管道或帳號、給誰、摘要、誰核准、結果、截圖或連結。

## 品牌核心九段（順序不換）
1 你是誰／2 產品與價格、做不到什麼／3 成功公式／4 客人／5 目標／6 客人原話／7 老闆怎麼講話／8 長什麼樣／9 紅線。每條標出處〔他說 10/17〕〔預約表〕〔網路〕〔我算的〕，不知道寫「待補」；最下面留改動紀錄。

## 怎麼算一位（客群）
- 新客：還沒買過。
- 熟客：照他的週期一直回來。
- 回頭客：買過，比平常久沒來。
- 流失客：超過三個月沒回；一年來不到 4 次的店，超過 12 個月才算。「回來了 N 位」只算流失客回來的。逐位去重。
