# 店家系統對照：老闆已經在用的系統，數字怎麼拿、放哪

> 以下是示範店，不是你的店。只串老闆真的在用、這期用得到的 1–3 個；其他的先記在帳號表「還沒串」。

## 先講規矩
1. 第一期一律走「老闆匯出 → 丟進收件匣或店裡的數字/原始檔/<來源>/」。最穩，不用金鑰。
2. 要用瀏覽器讀：老闆把登入存進設定 → Vault，我只看報表頁、不改設定、不退款、不改訂單；用完請他登出（紅線第 9 條）。
3. 官方 API 要金鑰的（Shopline、91APP、點點簽、NUEIP、Ragic、金流）：這期不碰。金鑰、token、HashKey 不收在聊天；老闆貼了請他刪掉、到平台重發一組。
4. 會員名單、訂單明細有電話信箱：原檔放著不分享，只算數字；名單只收有下一步的人（照〈公司大腦說明.md〉）。
5. 金流（綠界、藍新）只看交易彙總，不碰退款、撥款、金鑰。

## 拿到之後
- 檔名照 `來源-內容-起日_迄日`；老闆丟進收件匣的，搬到原始檔/<來源>/ 就算處理完。
- 分析師每週日把數字總表填好，記分板「總覽」多一行：「店家系統：這週營收＿、來客＿（來源＿）」；跟客人名單差很多就寫出來，不相加。
- 第一次串某個系統：讀一筆回來給老闆看（例：上週營業額那一格），讀不到就說沒拿到，不說已串好。
