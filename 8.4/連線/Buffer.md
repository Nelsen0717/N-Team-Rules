# Buffer（發文主路：Threads、IG、FB 粉專、Google 商家動態）

Threads、IG 有三條路：**Buffer（預設）**、瀏覽器（備用，照〈總覽.md〉）、自己的 Meta 小程式（進階，照〈Meta直連.md〉）。

Grok Bot 的連線目錄裡有 Buffer 官方連線（Buffer 自己的 MCP，OAuth 登入，不用金鑰）。老闆的社群帳號連在 Buffer，我透過 Buffer 存草稿、排程、發布、看成效。資料會經過 Buffer（第三方，不是 Meta、Google）。LINE 不在 Buffer 裡，照〈LINE官方帳號.md〉。

## 實測（2026-11-05 16:00）
用 Grok Bot 的 Buffer 連線、免費方案、3 個頻道（Threads、IG 商家帳號、FB 粉專）：存草稿（saveToDraft）、讀回（get_post 一致）、刪除（delete_post）都過。**放圖、真的發一則還沒測。** Google 商家沒有實接，只能說「Buffer 也能管 Google 商家」。

## 免費方案（2026-11 查 buffer.com/pricing，以官網為準）
- 3 個頻道；每個頻道同時最多排 10 則，發掉就補得回來（不是每月上限）。
- MCP 和 API 免費方案就有。
- 免費方案每個平台一輩子最多連過 8 個不同帳號。
- 要更多頻道或排更多則：付費方案（錢的事，老闆決定）。

## 每個平台要先確認的
| 平台 | 條件 | 自動發布 |
|---|---|---|
| Threads | 一般帳號就行；只要字，可串文 | 可以 |
| IG | 要專業帳號（商家或創作者）；一定附圖或影片 | 可以；個人帳號只能「到時間提醒你」 |
| FB 粉專 | 粉專管理員；社團不行（只有提醒） | 可以 |
| Google 商家 | 已驗證的商家；類型選最新消息、優惠、活動；最多 10 張圖，不能放影片 | 可以 |

## Buffer 做不到的（先講清楚）
- 讀不到留言、不能回別人的貼文：回留言、海巡回覆走瀏覽器或老闆自己貼。
- 限時動態、FB 社團：只能提醒，老闆用手機。
- 連線涵蓋整個 Buffer 帳號，`create_post` 可以直接發、`delete_post` 救不回：第一天請老闆在設定的「先問我」清單加上 Buffer 發布（照〈範例/核准轉達.md〉）。「先問我」擋不擋得到 Buffer 還沒實測，擋不到就在課上直說，只靠員工守規矩。

## 圖怎麼進 Buffer（IG 一定要圖）
Buffer 收圖要**公開的圖片網址**；員工電腦上的圖沒有網址，不能直接塞。三條路：
| 路 | 怎麼做 | 好處 | 風險 |
|---|---|---|---|
| A 瀏覽器上傳（**目前建議，待實測**） | 老闆把 Buffer 登入存進 Vault；員工先用連線存好文字草稿，再開 buffer.com 打開那則草稿上傳圖，截圖給老闆看 | 圖不用公開、全程員工做 | 網頁改版會壞；共用瀏覽器要記得登出 |
| B Drive 公開連結 | 圖放公司大腦，開「知道連結的人都能看」，把網址給 Buffer；發完收回權限 | 全走連線 | 分享檔案是 C 級，每次都要問；Drive 分享頁不一定是 Buffer 收得下的圖片網址，要測 |
| C 老闆在 Buffer App 附圖 | 員工存好文字草稿，老闆在手機 Buffer App 打開草稿附圖、按排程 | 最穩、不用登入 | 老闆多一步 |
三條都還沒實測。實測前跟老闆講：「Threads 我可以直接排；IG 的圖這週先用 C，我把草稿和圖傳給你。」A 測通才改講「IG 也交給我」。

## 帶老闆連（一則一步）
1. 「到 buffer.com 用你自己的信箱註冊，免費方案就夠。」
2. 先問：「免費只能連 3 個，Threads、IG、FB 粉專、Google 商家先挑哪三個？」再請他按 Connect channel，用自己的帳號登入同意。IG 要先在 IG 設定改成專業帳號。
3. 出 Buffer 連線卡請他按同意（Grok Bot 這邊登入 Buffer）。
4. 讀頻道清單，講「我看得到你的＿＿」。之後別的員工先讀頻道，讀得到就不再問（七位共不共用這個連線還沒實測）。看不到就說沒連成功，同一個錯兩次就改走瀏覽器或「你自己發」。

## 每一則（〈送出前把關〉B 級）
1. 存成 Buffer 草稿（saveToDraft），把全文、圖、管道、預定時間貼給老闆。
2. 老闆說「好」：照原文排時間（customScheduled）或立刻發（shareNow）。他想自己按：改成「到時間提醒你」（notification），Buffer 會推手機通知。
3. 改了字就重新給他看；他說「可以交給你」的固定欄目（例：每週五的本週新品），之後照排，送出紀錄照記。
4. 發完把連結和時間記進發文表；兩天後讀 Buffer 的成效（Threads、IG 有基本數字；Google 商家 Buffer 沒有成效，請他截圖或用瀏覽器看）。

## 不做
不刪老闆的貼文（刪了救不回）；不升級 Buffer 付費方案；不連老闆個人 FB（Buffer 本來就不支援）。
