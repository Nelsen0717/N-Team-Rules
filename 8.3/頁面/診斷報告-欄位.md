# 診斷報告頁的 D 欄位（配 診斷報告.tsx）

> 以下是示範店，不是你的店。老闆賣什麼、客人是誰，只看他的品牌核心和他講的；沒有就問，不拿這裡的例子當事實。
WriteCanvas 時內容＝診斷報告.tsx 原樣，只改第 2 行 `const D=`。之後每次複述確認，EditCanvas 只換這一整行。

| 欄 | 填什麼 |
|---|---|
| sample | 範例頁填 true，真的店填 false |
| shop、one、date | 店名、一句話你是誰、日期 |
| seg | 1 生意、2 六站（第 5 題複述後）、3 診斷（16 題問完）、4 請人（兩位到齊） |
| c | 16 個字，第 n 個＝第 n 題：A–D；不確定或跳過 E；還沒問 - |
| f | 第一眼 3 件，每件以「已驗證：」或「推測：」開頭；沒網址就留空 |
| t | 第 13 題用說明會那套填 1，否則 0 |
| win | 開放題原話（最近一位成交的客人怎麼找到你、為什麼買） |
| yr、pay | 一年來幾次、一次花多少；不知道填 0 |
| files | 老闆丟了幾樣資料 |
| img | 貼文最缺圖、行銷官換設計師時填 1 |
| old、ask | 先找第一位客人：問了幾位熟人、幾位新的人來問 |
| park、link、done | 之後再聊、還沒串、驗收過的員工，用「、」隔開（同一份也寫進目標與節奏） |

換完讀回，c 逐字比對；不一樣或失敗重試一次，再不行改出基本版。
