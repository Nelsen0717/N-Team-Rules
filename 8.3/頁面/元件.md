# 頁面元件（底稿）

> 這份是底稿：正式的畫圖元件之後會補上。現在先照下面的安全做法做；這份抓不到時，照範本裡的文字版（Section、Properties、Text，數字放最上面）。
> 以下是示範店，不是你的店。數字只寫有出處的；不知道寫「待補」，不當 0。

## 安全做法（每一頁都一樣）
1. 只用 Page、Section、Properties、Text 這四個元件，從 `grok/canvas` 匯入。
2. 數字放最上面：第一個 Section 用 Properties，一格一個數字（label 寫白話，value 寫數字和單位），下面才寫說明。
3. 一頁一件事；標題寫「頁名｜店名」。

```tsx
import{Page,Section,Properties,Text}from'grok/canvas';
const D={shop:'',date:'',nums:[['','']],note:''};
export default function App(){return(<Page lang='zh-Hant' title={'頁名｜'+D.shop} summary={D.date}><Section heading='數字'><Properties items={D.nums.filter(r=>r[0]).map(([label,value])=>({label,value}))}/></Section><Section heading='說明'><Text>{D.note||'待補'}</Text></Section></Page>);}
```

## 固定程式、只換資料行
- 程式放規則包，WriteCanvas 內容＝程式原樣，只改第 2 行 `const D=`。
- 之後更新用 EditCanvas 只換 `const D=` 那一整行，換完讀回比對；失敗重試一次，再不行用文字版。
- 程式裡不寫店家的資料，店家的資料只放在 `const D=` 那一行。

## 進度總表：六段進度條（開場一結束就建）
六段照順序：開場、看診斷、定方向、自介卡、員工到職、每天營運。走完的打 ✓，正在做的打 ●，還沒到的打 ○。開場一結束就建，第一段打勾；之後每走完一段當場更新，不重建。

```tsx
import{Page,Section,Properties,Text}from'grok/canvas';
const D={shop:'',date:'',done:1,goal:'',today:[''],team:[['','']],wait:['']};
const W=['開場','看診斷','定方向','自介卡','員工到職','每天營運'];
export default function App(){const L=(a:string[])=>a.filter(Boolean);return(<Page lang='zh-Hant' title={'進度總表｜'+D.shop} summary={'更新到 '+D.date}><Section heading='走到哪'><Text>{W.map((w,i)=>(i<D.done?'✓':i==D.done?'●':'○')+w).join(' ')}</Text><Properties items={[{label:'走完',value:D.done+' / 6 段'},{label:'兩週目標',value:D.goal||'待補'}]}/></Section><Section heading='今天'><Text>{L(D.today).join('；')||'今天沒有新的事'}</Text></Section><Section heading='團隊'><Properties items={D.team.filter(r=>r[0]).map(([label,value])=>({label,value}))}/></Section><Section heading='等你決定'><Text>{L(D.wait).join('；')||'沒有'}</Text></Section></Page>);}
```

| 欄 | 填什麼 |
|---|---|
| shop、date | 店名、最後更新日期 |
| done | 走完幾段（開場一結束填 1） |
| goal | 兩週目標走到哪，例「新的人來問 2 / 3 位」 |
| today | 今天最多三件 |
| team | 一位一列 [職稱, 狀態和最近一份成品]；還沒請先空著 |
| wait | 等老闆決定的事，最多三件 |

文字版（做不出頁面時貼在對話）：第一行寫六段（✓●○），下一行寫走完幾段和兩週目標，再寫今天、團隊、等你決定。
