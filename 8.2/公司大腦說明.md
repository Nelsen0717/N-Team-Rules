# 公司大腦說明（寫法和欄位）

> 以下是示範店，不是你的店。老闆賣什麼、客人是誰，只看他的品牌核心和他講的；沒有就問，不拿這裡的例子當事實。
範本裡只留資料夾清單和「怎麼算一位」。這份是怎麼寫。

## 品牌核心九段（順序不換）
1. 一句話你是誰：用老闆自己的話，不用標語。
2. 產品與價格、做不到什麼：主力 1–3 樣，寫價格區間；做不到的也寫，員工才不會亂答應。
3. 成功公式：最近一位成交的客人怎麼來、為什麼買（第 3 題後面那題的原話）。
4. 客人：誰、在哪、為什麼留下。
5. 目標：兩週目標＋兩個每天看得到的數字＋日期。
6. 客人原話：一字不改，附稱呼、日期、出處。
7. 老闆怎麼講話：他改過的句子寫成「原句 → 改句」，加上以前的貼文。
8. 長什麼樣：顏色、字、照片風格（設計師定）。
9. 紅線：這家店自己的不做清單（例：不打折、不接急件）。

每條標出處：〔他說 10/17〕〔預約表〕〔網路〕〔我算的〕；不知道寫「待補」。最下面留改動紀錄（日期、改了哪段、誰改）。第一天 1–6 段要有東西，從 16 題的答案寫。

## 客人名單欄位
| 欄 | 寫什麼 |
|---|---|
| 稱呼 | 老闆怎麼叫他，不寫全名 |
| 來源 | 介紹、社群、地圖、主動找、走進來 |
| 狀態 | 詢問（誰看到誰新增）→ 洽談（接待官：第一則回覆已送）→ 成交（說客：確認時段或付款）→ 備妥（接待官：須知或出貨通知已送）→ 完成（老闆說做完）→ 回流（接待官：再訂、評價或介紹）；停止＝說不要，永不再排 |
| 負責 | 職稱 |
| 下一步、下一步日期 | 一句話＋日期 |
| 最近一筆 | 日期和金額區間 |
| 上次到店、到店次數、週期（天） | 算回頭客和流失客用 |
| 客群 | 新客、熟客、回頭客、流失客 |
| 介紹人 | 稱呼 |
不放電話、信箱、地址、私事。

## 曝光/點子表 欄位
點子、來源（客人問過／同行／AI 檢查／老闆想到）、狀態（點子 → 排隊 → 寫好 → 老闆看過 → 已發；不做）、誰寫、哪天發、連結。

## 曝光/客人見證庫 欄位
原句（逐字）、誰說的（可匿名）、日期、出處、能支持哪一句話、同意狀態（沒問過／問過了／可以公開／只能匿名／改過字後同意／拒絕）。

## 怎麼算一位（客群）
- 新客：還沒買過。
- 熟客：照他的週期一直回來。
- 回頭客：買過，比平常久沒來。
- 流失客：超過三個月沒回；一年來不到 4 次的店，超過 12 個月才算（333 算這群）。「回來了 N 位」只算流失客回來的。逐位去重。
